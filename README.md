This project is an independent data analysis exploring factors that may influence the success of K-pop groups. Using a limited curated dataset, I examined relationships between variables such as company affiliation, debut timing, and other contextual characteristics to identify potential patterns associated with group visibility and performance.

The project was fully self-directed — from selecting the research topic and framing the questions to conducting the analysis, interpreting results, and communicating findings. All analysis was performed in Python, with an emphasis on exploratory data analysis, basic statistical reasoning, and clear data storytelling.

In addition to the technical analysis, the project includes:
- A policy-brief style report outlining methodology, analytical approach, key findings, and implications
- A short-form content example demonstrating how the analysis could be communicated to a broader audience in an accessible format

This project reflects both technical data analysis skills and an interest in applying data science methods to cultural and entertainment industry questions.
